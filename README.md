# 社群行為準則 Code of Conduct

揪鏡是一個保護隱私、對抗偷拍的公益專案。我們的社群必須先是一個安全的空間。

本準則適用於所有 揪鏡 JiuJing 社群空間：GitHub（Issue、PR、Discussion）、Discord、讀書會、線上與實體活動，以及以專案身分進行的任何交流。

---

## 零容忍條款 — 違反即永久移除

以下行為**不警告、不討論，直接永久移除**（踢出並封鎖所有社群空間）：

1. **詐騙（Scam）**：詐騙、釣魚連結、假冒團隊成員、虛假募款、惡意軟體、以專案名義謀取不當利益。
2. **NSFW 內容**：張貼、傳送或連結任何色情、裸露、性暗示內容。**偷拍影像、未經同意的私密影像一律視為最嚴重違規，並將通報警方。**
3. **性騷擾**：對任何人進行性騷擾，包括不受歡迎的性暗示言論、追求、私訊騷擾、評論他人外貌或身體。

以上適用於**所有人**，包括團隊成員及創辦人。

---

## 基本規範

以下行為會先收到警告；情節嚴重或屢勸不聽者，將暫時或永久移除：

- 人身攻擊、辱罵、霸凌
- 基於性別、性傾向、族群、宗教、身心障礙、年齡、外貌等的歧視言論
- 公開他人私人資訊（肉搜、人肉）
- 洗版、廣告、與專案無關的推銷
- 刻意散布偷拍相關的**攻擊技術教學**（研究防禦手法的技術討論除外，請在讀書會頻道進行）

## 檢舉方式

- **Email**：[聯絡信箱]（僅核心團隊可讀）
- **Discord**：私訊任一版主

請盡量附上截圖或連結。檢舉人身分**絕對保密**。
檢舉內容涉及核心團隊成員時，該成員不參與處理。

---

## 處理流程

1. 版主收到檢舉後 **48 小時內**回應。
2. 零容忍條款：確認屬實後**立即**移除。
3. 基本規範：警告 → 暫時停權 → 永久移除。
4. 被處分者可來信申訴一次。零容忍條款的處分不受理申訴。
